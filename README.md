# Aim Trainer

## Описание

Aim Trainer — это игра, созданная с использованием библиотеки Pygame, которая помогает пользователям улучшить свои навыки стрельбы. Игроки должны попадать в цели, которые появляются случайным образом на экране. Игра отслеживает результаты в реальном времени,что помогает тренировать игровые навыки даже во время учебной деятельности.

## Инструкция по установке 

### Необходимо поочередно вписать следующие команды:
- "python -m venv venv"
- "source venv/bin/activate"
- "pip install -r requirements.txt"
- После чего необходимо запустить программу командой: "python main.py"

## Структура проекта

### Константы

- WIDTH, HEIGHT: Ширина и высота окна игры.
- WIN: Окно игры.
- TARGET_INCREMENT: Время (в миллисекундах), через которое появляются новые цели.
- TARGET_EVENT: Пользовательское событие для генерации целей.
- TARGET_PADDING: Отступ для генерации целей.
- BG_COLOR: Цвет фона окна.
- LIVES: Количество жизней у игрока.
- TOP_BAR_HEIGHT: Высота верхней панели с информацией.
- LABEL_FONT: Шрифт для отображения текста.

### Классы

#### Класс - Target:

Представляет цель, которая появляется на экране.

- MAX_SIZE: Максимальный размер цели.
- GROWTH_RATE: Скорость роста/уменьшения цели.
- COLOR: Основной цвет цели.
- SECOND_COLOR: Вторичный цвет для визуальных эффектов.

Методы:
- init(self, x, y): Инициализирует координаты и размер цели.
- update(self): Обновляет размер цели, заставляя её расти и уменьшаться.
- draw(self, win): Отрисовывает цель на переданном окне.
- collide(self, x, y): Проверяет, произошло ли столкновение с целью.

#### Класс - Display:

Управляет отрисовкой всех элементов на экране.

Методы:
- draw(win, targets): Отрисовывает фон и цели на экране.
- draw_top_bar(win, elapsed_time, targets_pressed, misses): Отрисовывает верхнюю панель с информацией о времени, скорости, попаданиях и жизнях.
- end_screen(win, elapsed_time, targets_pressed, clicks): Отображает экран завершения игры с итогами.

#### Класс - Stats:

Отслеживает статистику игрока.

Методы:
- init(self): Инициализирует счетчики для попаданий, кликов и промахов.
- record_hit(self): Увеличивает счетчик попаданий.
- record_miss(self): Увеличивает счетчик промахов.

#### Класс - Game:

Основной класс, управляющий игровой логикой.

Методы:
- init(self): Инициализирует параметры игры и запускает таймер для генерации целей.
- run_game(self): Основной игровой цикл, обрабатывающий события и обновляющий состояние игры.

### Функции

- format_time(secs): Форматирует время в строку в формате MM:SS.m.
- get_middle(surface): Возвращает координаты для центрирования текстового элемента.
- wait_for_exit(): Обрабатывает события выхода из игры.
